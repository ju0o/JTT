# JTT RC3 빠른 시작

[English](JTT_QUICK_START.md) · [README](../README.ko.md)

Linux/WSL2의 공식 `jtt-v0.3.0-rc3` / 패키지 `0.3.0rc3` 기준입니다.
[README의 보호된 공식 설치 명령](../README.ko.md#공식-rc3-설치)으로 설치한 뒤 `jtt --version`, `jtt doctor`, `jtt`를 실행하세요.

## 1. 생성과 입력

UI를 여는 것만으로 셸은 실행되지 않습니다. LEFT Window를 선택하고 Ctrl+G 다음 n을 4초 안에 누릅니다.
새 CENTER 카드가 선택되고 세션·렌더러·입력 임대가 준비된 경우에만 RIGHT 입력 모드로 전환됩니다.
오류가 보이면 터미널을 반복 생성하지 말고 원인을 확인하세요.

RIGHT에서 다음 무해한 명령을 입력하고 Enter를 누릅니다.

```sh
printf 'Hello JTT\n'
```

이제 일반 키는 해당 셸로 전달됩니다. Ctrl+]는 탐색 복귀입니다.
탐색 모드의 Tab / Shift+Tab으로 패널을 이동하고, CENTER 카드에서 Enter로 RIGHT에 이동한 뒤 Enter 또는 RIGHT 클릭으로 입력 권한을 요청합니다.
연결 실패·신원 불일치 상태에서는 입력하면 안 됩니다.

## 2. 터미널과 Window 전환

Ctrl+G n은 현재 Window에 독립 터미널을 하나 더 생성합니다.
Ctrl+G h / l은 이전 / 다음 카드를 선택하고 탐색으로 복귀합니다. 입력하려면 RIGHT에 다시 진입하세요.
RIGHT에 표시된 입력 대상이 선택 카드와 일치하는지 확인합니다.

Ctrl+G w로 LEFT를 선택하고 `+ 새 Window`에서 이름을 입력합니다.
이는 **빈 논리 그룹**이며 셸이나 OS/tmux Window를 만들지 않습니다.
Window를 선택하면 LEFT 포커스를 유지한 채 CENTER/RIGHT가 바뀌며 기존 셸은 계속 실행됩니다.
Tab으로 LEFT를 벗어납니다. 이름 변경·제거와 기존 폴더 접근은 `설정 · 메뉴`에서 제공합니다.
논리 Window 제거는 터미널 종료가 아니며 참조를 기본 위치로 돌려놓습니다.

## 3. 보관함: 세션 참조와 템플릿

LEFT에서 `보관함`을 엽니다.

| 탭 | 의미 | 열었을 때 |
| --- | --- | --- |
| 저장한 작업 | 기존 터미널 세션 참조 | 신원이 일치하는 정확한 세션을 불러와 재연결 |
| Work Kit | 이름·역할·선택 경로와 1~4개 카드 배치 | 미리보기만 표시; 셸·Agent·SSH·명령 실행 없음 |

Tab / Shift+Tab으로 목록·작업 버튼·탭 사이를 이동합니다. 탭에서는 좌우, 목록에서는 위아래 방향키를 사용합니다.
목록에서 Enter는 작업 버튼으로 이동하며 작업을 선택한 뒤 Enter로 실행합니다. 마우스 선택도 지원합니다. Esc는 닫기·취소입니다.

Kit은 `새 Work Kit`에서 카드를 추가·제거하고 터미널 이름·역할·선택 작업 디렉터리를 편집한 뒤 저장합니다.
역할은 선택 목록과 사용자 지정, 경로는 폴더 탐색과 직접 입력을 제공합니다.
저장 성공 안내 후 템플릿 미리보기가 선택됩니다. `편집`으로 기존 구성을 바꾸며 Esc는 미저장 변경을 취소합니다.
미리보기는 실행이 아니며 RC3에는 Work Kit 실행 기능이 없습니다.

`현재 구성 저장`은 저장한 작업 기능입니다. 출력이나 프로세스 스냅샷이 아니라 세션 참조를 저장합니다.
사라진 세션은 연결 끊김으로 남으며 불러오기로 새로 만들거나 재부팅 전 프로세스를 복원하지 않습니다.
이름 변경·삭제 작업은 대상을 명시하며 필요한 확인 절차를 거칩니다. Kit 삭제는 템플릿에만 적용됩니다.
작업공간 삭제는 셸 종료가 아니며 기본 작업공간은 삭제할 수 없습니다.

## 4. 분리·재연결·종료

- **Ctrl+G d:** UI만 분리하고 터미널은 유지합니다. 같은 사용자·상태 경로로 `jtt`를 다시 열어 재연결합니다.
- **Ctrl+G x:** 취소 우선 확인 후 선택 터미널을 종료합니다. 종료가 확정된 세션은 해당 카드 참조를 정리합니다.
- 연결 불명확은 종료 증거가 아닙니다. Ctrl+G r 재확인이나 명시적 참조 관리 기능을 사용하고 소켓·상태 파일을 삭제해 복구하려 하지 마세요.
- 탐색 모드 q/Q/Esc는 UI 분리가 아닙니다. 입력 모드에서는 터미널로 전달됩니다. Esc는 대화상자 또는 Prefix 대기를 취소합니다.

UI 분리와 재부팅 후 복원은 다릅니다. Supervisor 장애나 시스템 재시작으로 세션이 끝날 수 있습니다.

## 5. 예약 키와 제한

Ctrl+G는 JTT Prefix이며 다음 명령은 4초 안에 입력해야 합니다.
Ctrl+G Esc는 취소, Ctrl+G ?는 도움말입니다.
입력 모드의 Ctrl+G Ctrl+G는 원래 Ctrl+G, Ctrl+G Ctrl+]는 원래 Ctrl+]를 전달합니다.
이 키를 사용하는 프로그램에서 우회 입력에 사용하세요. 사용자 지정 키가 있으면 문서의 기본값보다 화면 안내를 따르세요.
[키 설정·프로토콜 제한](JTT_TERMINAL_SUPPORT.md)을 확인하세요.

JTT는 샌드박스가 아닙니다. 셸은 사용자 권한과 로그인 설정을 사용합니다.
AI 로그인·모델 자동 호출은 JTT 기능이 아닙니다.
완전한 xterm 에뮬레이터가 아니며 확장 키·마우스 보고·bracketed paste·임의 터미널 질의에 제한이 있습니다.
Clipboard와 실제 WSL 재시작 복구는 미검증입니다.
