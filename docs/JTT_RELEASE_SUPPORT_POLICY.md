# JTT 정식 출시 지원 정책 — WBS-R00 부록

- 승인 기준일: 2026-10-26 (KST)
- 적용 기준: [JTT Release WBS v1.0](JTT_RELEASE_WBS.md)
- 상태: **R00 지원 계약 승인 · RELEASE HOLD**

이 문서는 Founder가 승인한 최초 정식 출시 지원 범위의 기록이다. 기준 WBS 원문은 변경하지 않는다. 이 승인만으로 제품 지원 검증, PR 병합, RC 승인, Tag, Release 또는 PyPI 게시가 승인된 것은 아니다.

위 지원 조합은 5개 OS/배포 환경과 3개 Python 버전, 총 15개 환경 셀이다. 지원 선언에는 각 셀의 실제 설치·실행 증거가 필요하다. uv tool은 기본 설치 경로다. pipx와 격리 venv도 공식 대안으로 안내하려면 R08에서 해당 경로의 설치·업데이트·삭제·복구 검증을 기록해야 한다. 한 환경에서의 성공을 다른 OS, 배포판 또는 Python 버전의 통과로 간주하지 않는다.

## 최초 출시에서 제외하는 대상

- **Windows 10:** 호환성 연구만 수행한다. 최초 정식 출시의 공식 지원 대상이 아니다.
- **macOS 및 기타 Linux 배포판:** 최초 정식 출시 지원 대상이 아니다. 검증 전 지원을 표시하지 않는다.
- **Python 3.9 및 3.10:** 신규 정식 출시의 지원 목표에 포함하지 않는다. 공개 RC3의 기존 지원 계약은 변경하지 않는다.

Windows 10 연구 결과는 별도로 기록하며 최초 출시의 통과 증거로 재사용하지 않는다. 향후 Windows 10 지원을 추가하려면 Founder의 새 범위 승인이 필요하다.

## 배포·설치 소유권

- 새 배포명은 `ju0-terminal-tower`, 실행 명령은 `jtt`다.
- 기본 설치 방식은 `uv tool`; 대안은 `pipx` 및 격리된 venv다.
- uv/pipx가 관리하는 환경의 설치·업데이트·삭제는 각 패키지 관리자가 소유한다. JTT 자체 업데이트 기능은 이 환경을 직접 변경하지 않는다.
- 기존 공식 RC3 `tmux-agent-tower 0.3.0rc3`와 `jtt-v0.3.0-rc3`의 계약은 유지한다. 자동 이전, 덮어쓰기 또는 기존 PATH 명령 교체를 하지 않는다.
- 기존 JTT_HOME 및 실행 중 PTY를 보호한다. 새 패키지 버전, PyPI 이름 소유권·게시 여부 및 게시 대상은 해당 Release Gate에서 별도로 결정한다.

## E2E 및 Human Gate 적용 기준

WBS 원문의 WBS↔E2E 추적표를 유지한다. R00의 직접 추적은 **E2E-021 및 E2E-022**다. 실제 설치·실행 증거는 원문에 정의된 **E2E-001**, 지원 OS/Doctor 확인은 **E2E-021**, exact RC 후보 설치 검증은 **E2E-023**에서 각각 기록한다.

| 시험 | 적용 기준 |
|---|---|
| E2E-021 OS startup/doctor | Windows 11 네이티브, Ubuntu 22.04/24.04 네이티브, WSL2 Ubuntu 22.04/24.04에서 지원 Python별 확인. Doctor는 읽기 전용이어야 한다. Windows 10 결과는 연구로 분리하며 출시 통과 셀에 포함하지 않는다. macOS 및 기타 배포판은 N/A다. |
| E2E-001 설치·실행 | 승인된 지원 환경 셀별로 격리 설치, 버전/Doctor, 실행 및 제거 결과를 기록한다. 실제 사용자 환경을 사용하지 않는다. |
| E2E-023 RC 후보 | exact SHA와 빌드 산출물을 격리 환경에 설치하여 검증한다. 공개 Tag/PyPI 게시 없이 수행한다. |
| HG-W11-01/02/03 | Windows 11 네이티브 검수에 적용한다. |
| HG-LNX-01 | Ubuntu 네이티브 지원 범위에 적용한다. 증거에는 실제 Ubuntu 버전을 기록한다. |
| HG-WSL-01 | WSL2 지원 범위에 적용한다. 증거에는 Ubuntu 버전을 기록한다. |
| HG-INST-01 | Windows 및 Linux 설치 흐름에 적용한다. 기존 런처·PATH·JTT_HOME·세션 보호를 확인한다. |
| HG-W10-01 | 최초 출시 판정에는 **N/A**다. 별도 Windows 10 호환성 연구로만 기록하며 지원 PASS로 표시하지 않는다. 향후 지원 추가 시 Founder 승인 후 필수 Gate로 재활성화한다. |

Human Gate는 자동 테스트를 대체하지 않는다. 자동 테스트 또한 실제 사용자 UX 승인을 대체하지 않는다.

## R00 및 G0 증거 기록

- Founder 결정: 2026-10-26에 위 OS, Python, 설치 방식 및 RC3 보호 경계를 승인했다.
- 문서 증거: 이 부록과 기준 WBS 원문을 함께 검토한다. 기준 WBS 파일은 별도 문서 PR에 포함되고 이 부록에서 내용을 수정하지 않는다.
- **WBS-R00 상태:** `SUPPORT CONTRACT APPROVED`. 이는 지원 범위 결정의 승인 상태이며, 실제 OS 설치·실행 검증 완료를 뜻하지 않는다.
- **G0 증거:** 공식 지원/비지원 매트릭스와 설치 소유권이 승인되어 범위 결정 증거를 기록했다. 이는 Release GO가 아니며, 출시 상태는 계속 `HOLD`다.
- 다음 검증: 각 지원 환경의 E2E, R08 패키지 메타데이터 정합, 관련 Human Gate 및 후속 Release Gate를 통과해야 한다.

## 현재 저장소 문서·메타데이터와의 정합 작업

이 부록은 기존 RC3 안내나 제품 메타데이터를 변경하지 않는다. 다음 항목은 해당 WBS에서 별도로 정렬한다.

1. 현재 `pyproject.toml`은 `requires-python >=3.9` 및 Linux OS classifier를 선언한다. 새 지원 목표인 Python 3.11–3.13과 Windows 네이티브 지원 메타데이터는 **R08의 별도 Draft PR**에서 변경·검증한다.
2. 현재 README의 공식 RC3 설치 안내는 Linux/WSL2와 Python 3.9 이상을 대상으로 한다. 기존 RC3 계약은 유지하고, 신규 정식 배포 문서에서 RC3와 새 배포 경계를 분명히 한다.
3. 현재 `ju0-terminal-tower 0.3.1rc0`은 미공개 후보로 취급한다. 이 문서는 그 버전을 정식 출시 버전으로 승인하지 않는다.
4. 현재 Linux CI 행렬은 Python 3.9/3.11/3.13이다. 신규 출시 행렬은 승인 목표인 3.11/3.12/3.13으로 조정하고 Windows 및 각 Ubuntu/WSL2 환경의 실제 검증을 포함해야 한다. CI 정책 변경은 R10에서 별도 검토한다.

이 지원 정책은 실제 검증 결과가 수집될 때까지 목표 범위다. 검증되지 않은 환경은 지원 완료로 홍보하지 않는다.
